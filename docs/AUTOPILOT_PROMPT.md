# برومت التشغيل الذاتي (الصقه في Antigravity)

افتح جلسة جديدة في مجلد المشروع، والصق:

```
أنا طالب ماستر أنظمة مدمجة. نبني "خزانة الأفكار": منصة تحفظ أفكاري وتمنع تشتتي، ثم تحوّل الفكرة إلى نموذج أولي IoT (كود ESP32 + لوحة تحكم + محاكاة). أولويتي الآن أن تعمل نسخة الهاتف لأجربها.

اقرأ بالترتيب: docs/ARCHITECTURE.md ثم docs/PLAN.md ثم الكود الحالي.
الحالة: نفّذت فقط تحويل المشروع إلى Vite + TypeScript. لم يُنفَّذ IndexedDB بعد.

لخّص لي في 6 أسطر: فهمك للمعمارية، وحالة الكود، وما ستفعله أولاً. ثم نفّذ docs/PLAN.md بدءاً من S1 وفق "بروتوكول العمل" حرفياً:
- خطوة واحدة في كل مرة، وكل خطوة تنتهي بـ build + اختبارات + التحقق من معايير القبول + تسجيل الدليل في PLAN.md + git commit.
- تابع تلقائياً إلى الخطوة التالية فقط إذا تحققت كل معايير القبول.
- توقف عند أي علامة 🛑 وأعطني الخطوات اليدوية بدقة، أو عند فشل متكرر مرتين لنفس المشكلة.
- لا تعمل شيئاً خارج نطاق الخطوة الحالية، ولا تنتقل إلى M2 قبل أن أقول "M1 نجح".
```

## نصائح
- ابدأ جلسة جديدة عند كل مرحلة (M1 ثم M2…) والصق البرومت نفسه مع تعديل سطر "الحالة".
- قبل البدء نفّذ في المجلد: `git init` ثم `git add -A` ثم `git commit -m "قبل الخطة"` ليكون عندك رجوع آمن.
- إن لم تُنهِ خطوة بنجاح فقل للمساعد: "ما فشل بالضبط؟ أعطني الدليل".

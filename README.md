# 🗄️ خزانة الأفكار (Idea Vault)

تطبيق ويب شخصي موجّه لطالب ماستر أنظمة مدمجة لمناقشة وتنظيم أفكار المشاريع (برمجية، عتادية، إلكترونيات، Edge AI) وتجنب التشتت والتركيز على الأهداف الأساسية.

## 📁 هيكلية المشروع (Vanilla TS + Vite)

```text
├── index.html          # الصفحة الرئيسية ونقطة دخول Vite
├── src/
│   ├── types.ts        # تعريف واجهة Idea وجميع الأنواع المشتركة
│   ├── config.ts       # الثوابت والإعدادات الافتراضية
│   ├── store/
│   │   └── index.ts    # طبقة التخزين (localStorage حالياً)
│   ├── llm/
│   │   └── index.ts    # واجهة التخاطب مع نماذج الذكاء الاصطناعي (Gemini, Anthropic, OpenAI/Ollama)
│   ├── prompts/
│   │   └── index.ts    # برومبتات المستشار وتحويل الفكرة إلى بطاقة JSON
│   ├── export/
│   │   └── index.ts    # دوال التصدير (Markdown, JSON, برومبت لمساعد خارجي)
│   ├── ui/
│   │   └── index.ts    # إدارة واجهة المستخدم والأحداث
│   └── main.ts         # تهيئة التطبيق وتثبيت المعرّفات العامة
├── package.json
├── tsconfig.json
└── vite.config.ts
```

## 🚀 طريقة التشغيل

### 1. تثبيت الحزم (إذا لزم الأمر):
```bash
npm install
```

### 2. تشغيل بيئة التطوير المحلية:
```bash
npm run dev
```
سيفتح التطبيق محلياً عبر الرابط: `http://localhost:3000`

### 3. بناء نسخة الإنتاج:
```bash
npm run build
```

### 4. معاينة نسخة الإنتاج:
```bash
npm run preview
```
